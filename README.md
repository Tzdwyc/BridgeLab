# BridgeLab

BridgeLab 是一款本地运行的桥牌练习软件。玩家坐南家，与北家机器人搭档，对阵东西两位机器人；可练习叫牌和打牌、建立自定义牌例，并使用双明手分析室复盘。

## 当前版本：v0.3.6

本版新增首页、历史牌局档案和双桌 IMP 比赛，电脑端与 Android 均可离线使用。电脑端需要 Node.js 22.12 或更新版本。完整功能、启动、升级、备份和验证边界见 [v0.3.6 使用说明](versions/v0.3.6/README.md)。

## 快速启动

在 `versions/v0.3.6` 安装依赖并构建后运行 `npm start`，然后打开 `http://localhost:5196`。也可按使用说明直接运行随版本提供的启动脚本或完整包。Android 用户可安装 [v0.3.6 APK](versions/v0.3.6-mobile/release/BridgeLab-v0.3.6-mobile-android.apk)。

## 当前版本的不足

- Android 安装升级、WebView 和系统文件选择器尚未在真实设备上验证；相关证据来自构建检查和浏览器模拟。
- 桥牌 AI 的叫牌与打牌能力仍有限，不能替代完整竞赛级桥牌程序或专业教学判断。
- 本地牌局档案依赖浏览器或应用存储；清除站点数据、禁用存储或卸载应用可能丢失记录，请定期导出备份。
- 历史版本文档和测试材料保留了各版本的验证范围；不要把旧版报告视为 v0.3.6 的新验证结论。
