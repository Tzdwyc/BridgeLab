# BridgeLab 版本目录

`versions` 保存彼此独立、可并行运行的正式版本目录。不得用新版本文件覆盖旧版本，也不得删除旧版构建产物来“清理”当前开发目录。

- `v0.1`：原始归档版，默认端口 5188，仅保留与核验。
- `v0.2`：冻结版，默认端口 5189；后续修复不再直接写入此目录。
- `v0.3`：冻结电脑端基线，默认端口 5190；与 `v0.3-mobile` 一并只读保留。
- `v0.3-mobile`：冻结安卓基线，对应 v0.3。
- `v0.3.1`：保留上一版，默认端口 5191。
- `v0.3.2`：已交付并保留的修订版，默认端口 5192；默认使用 SAYC＋2/1 进局逼叫＋RKCB 1430。本次修复已由 GPT 审阅发现的共性问题，完整审阅范围与未完成部分见本版测试报告。

- `v0.3.3`：新版独立子目录，端口 5193；采用当前 v0.3.2 新牌桌，完成此前未审验的 2000 副逐步 GPT 审阅与共性修复，实际验证范围见本版测试报告。
- `v0.3.3-mobile`：对应 v0.3.3 的 Flutter 安卓工程与离线 APK，内置同一新牌桌，沿用应用标识与签名。

仓库根目录下的 `v0.2` 是此前工作留下的临时副本，不代表当前活跃版本。正式版本状态以本目录为准；确认不再需要前，不删除该临时副本或任何旧版产物。

- `v0.3.4`：本轮活跃电脑端，独立子目录及端口5194；继续同一原2000副逐步GPT审阅与修复，交付状态见其测试报告。
- `v0.3.4-mobile`：对应v0.3.4的新牌桌安卓工程，应用标识与签名保持升级兼容。
- `v0.3.5`：保留版，电脑端端口5195；v0.3.6 的前序版本。
- `v0.3.5-mobile`：对应 v0.3.5 的 Android 工程。
- `v0.3.6`：当前电脑端正式版，端口 5196；新增首页、历史牌局档案和双桌 IMP 比赛。详见本版 README 与测试报告。
- `v0.3.6-mobile`：对应 v0.3.6 的 Android 工程和离线 APK；真实设备安装升级与系统文件选择器尚待实机验证。
