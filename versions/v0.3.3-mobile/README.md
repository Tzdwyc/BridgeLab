# BridgeLab v0.3.3 Android

Reuses the v0.3.2 Flutter/WebView wrapper and desktop interface.
The final v0.3.3 desktop build, DDS and play advisor are bundled offline.
Build with PowerShell 7: `./scripts/build-android.ps1`.
Install `release/BridgeLab-v0.3.3-mobile-android.apk`.
Version name 0.3.3, version code 33; existing application ID and signing identity retained.
Installation and real phone interaction status are documented in docs/VALIDATION.json.
