# BridgeLab v0.3.7

固定单屏桥牌桌、牌例工作台与双明手分析。叫牌历史在固定小框内上下滚动，其他长内容通过页签和分页查看。v0.3.6 独立保留。

## 电脑端启动

解压完整包，双击“启动BridgeLab-v0.3.7.cmd”，打开 http://localhost:5197/#/home 。启动器使用本机 Node.js 提供已构建的静态资源，不需要安装开发依赖。若未安装 Node.js，启动器会给出提示。

保留启动窗口；关闭窗口会停止本地服务。首次打开等待页脚显示“离线资源已缓存”，之后断网仍可打开与分析。

### 继续 v0.3.6 的浏览器记录

端口 5197 和原 5196 是不同的浏览器站点。新端口没有旧记录不代表旧数据已删除。

可任选其一：

1. 在原版历史页面导出存档，在新版导入。
2. 关闭占用 5196 的旧版启动窗口，再双击“从v0.3.6地址升级启动.cmd”。新版继续使用 http://localhost:5196 ，沿用同一站点的记录。
3. 若原来使用 5195，则使用“从v0.3.5地址升级启动.cmd”。

本版继续使用 v3.6 的会话、比赛和牌例存储键，不改变数据格式。升级和导入兼容旧精确制记录，但新局不提供精确制选项。

## 安卓端

安装同级 v0.3.7-mobile/release/BridgeLab-v0.3.7-mobile-android.apk。这是原包名的升级包，保持签名配置和本地来源地址。安装前不必卸载旧版；卸载或清除应用数据会删除本机记录。

最终 APK 路径、哈希、签名及验证边界见移动工程 docs/VALIDATION.json、docs/UPGRADE_SIGNATURE_VALIDATION.json 和 docs/POSTBUILD_SOURCE_NOTES.json。安卓系统文件选择器和真实设备触摸仍需实机确认，浏览器模拟结果不代表实机测试。

## 本轮变化

- 固定单屏绿色牌桌，电脑四方位置为北上、南下、西左、东右。
- 比分采用南北／东西双竖柱，直接显示已得墩数；庄家方有成约目标线，不显示左侧刻度。
- 叫牌先选阶数，再选花色／NT；Pass、X、XX 常驻，保留 STOP 与长按／悬停说明。
- 叫牌历史取消分页，表头固定；在列表底部时跟随最新叫品，上翻查看时保持当前位置。
- 普通界面不展示DDS回退、降级和内部诊断，打牌提示直接显示建议牌。
- 自己的手牌固定在南家下方，明手留在原座位并在轮到时高亮可出牌；不提供手牌切换或自动换位。
- 东、西明手按黑桃、红心、方块、草花分行显示真实牌面；同花色横排，长套采用牌扇，避免花色混排。
- 首页与比赛设置使用紧凑按钮组；历史按比赛、单副与两桌分页查看。
- 分牌使用座位和花色页签，牌例库分页；保存、模拟按钮保持可见。
- 分析默认牌桌，逐墩、候选、总表、叫牌、分支与说明通过页签查看；保留 ALL PASS、声称截断和导入导出。
- 暂时隐藏精确制的新局与体系卡入口。
- 叫牌／打牌策略、DDS、计分和信息隔离沿用 v0.3.6；新比赛的软件版本标记为 0.3.7。
