## 已确认的共同原因

- 相同阶数不表示相同点力：敌方占掉较低空间后的最低支持，不是自主跳叫邀请。点力上下限及逼叫状态必须读取完整前缀。
- 第一次原套重复可能本次才显示更多长度。说明应区分“本次进一步显示”与“保留此前承诺”，不得倒置公开信息来源。
- 无将方在接受高花转移后选择4高花是支持。此前最低接受只保证二张，本次才保证三张以上；不能说成自己持长套。
- Stayman后另一高花邀请的最低2NT是拒邀；开叫人接受普通自然2NT时须用实际公开平台范围，不能套上20–21。
- 强加倍、逆叫和邀请收到最低自然回答后，其已有强力仍须保留。履行一轮逼叫不等于已完成成局要求，也不自动把零点被迫回答变成有点力。
- 无将快捷分支有时抢在Stayman、转移、真实高花应叫、已确认配合及二盖一描述之前。
- 满贯判断有时借助错误的支持长度、假的邀请下界或未显示的控制。安全控制试探和RKCB必须使用当家牌与此前公开信息，不能使用真实隐藏伙伴。
- 初次高花或低花支持有些按HCP判断，有些按支持点判断，且说明与策略口径不一致。确认至少八张才计短门与额外将牌；未确认时保留原始HCP。
