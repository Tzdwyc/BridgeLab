# BridgeLab v0.3.1 变更

v0.3 已冻结。v0.3.1 使用独立目录、端口 5191、浏览器存档键和离线缓存。

## 上下文叫牌说明

- 删除“自然叫牌／加叫；范围详见体系卡”占位说明。
- 电脑悬停、手机长按和键盘聚焦均调用同一解释器。
- 长拍卖兜底说明改为明确列出自然无将用途、止张要求、配合张数、长套再叫、扣叫及逼叫延续状态，不再显示“当前序列没有更窄范围”一类占位文字。
- 提示底部加入“v0.3.1 · 10月10日修订”标识，便于直接判断页面是否仍由旧缓存提供。
- PWA 改为自动更新，缓存标识升级为 `bridgelab-v0.3.1-r2`；新 Service Worker 使用立即等待跳过和客户端接管。
- 常见开叫、应叫、再叫、竞争叫、加叫、逼叫、RKCB 和 Pass 直接说明点力、套长、配合与逼叫性质。
- 按叫品在序列中的角色区分同形叫品：自然 `2♣` 争叫不再显示强开叫含义；技术性加倍后的扣叫不再显示 Michaels；强 `2♣` 的 `2♦` 等待、第二次负应叫、Stayman 答叫、Jacoby 转移接受、第四花色、弱二 `2NT` 特征问叫、RKCB 问 Q／问 K／签约均使用各自的说明。
- 对当前体系没有定义的非常规叫品明确显示“未定义精确范围”，不伪造约定含义。

## 默认 SAYC＋2/1 进局逼叫＋RKCB 1430

- 明确一阶低花后的 SAYC 自然 `2NT` 应叫：13–15 HCP、均型、无可在一阶应叫的四张高花，并逼叫进局。`5-3-3-2` 持五张开叫低花支持时仍按此定量应叫；叫品悬停／长按说明不再含糊写成“邀请以上”。
- `1M–1NT` 固定为 5–12 HCP 半逼叫。均型最低限开叫人可 Pass；18–19 HCP 均型牌再叫 `2NT`；非均型牌持四张第二套时自然再叫，六张开叫高花而无四张第二套时再叫 `2M`。固定牌例 `1♠–1NT` 后，`5♠-1♥-3♦-4♣`、15 HCP 再叫 `2♣`。
- 开叫人展示第二套后，应叫人比较公开可知的联手套长。固定牌例 `1♠–2♦–2♥` 后，三张黑桃与开叫人五张黑桃形成 8 张配合，优先于三张红心与四张红心形成的 7 张配合，因此叫 `4♠` 而不是 `4♥`。
- 未 Pass 且无干扰的二盖一新花色应叫为 13+ HCP 并建立进局逼叫。逼叫持续到本方成局，不只要求下一轮再叫；`1♠–2♦–2♠–Pass` 与 `1♠–2♥–3♣–Pass` 均被硬规则禁止。
- Q 问叫后的六阶旁门 K 答叫只描述将牌 Q 与该门 K，不把旁门改为最终将牌；问叫方会回到六阶已确认将牌。`5NT` 旁门 K 问叫及其六／七阶签约逻辑保持独立。
- 新增 172,499 个约定卡派生位置，其中 5,802 个半逼叫位置、14,484 个自然高花／负加倍分流位置、9,996 个开叫下限位置、64,224 个后续干扰下的二盖一进局逼叫位置、22,848 个二盖一续叫位置、43,008 个双方套约定叫移除位置，以及低花无将应叫、高花优先和自然无将再叫边界。每一步独立检查逼叫状态、合法性、公开成局底线和已知配合选择。
- 长序列根因修正包括：自然 `2♣` 争叫不再按 22+ HCP 计入同伴下限；弱二开叫在对手插叫后仍履行同伴新花色的一轮逼叫；转移接受只保证 2+ 张，之后支持才提高到 3+ 张；二盖一中的开叫高花再叫不凭重复叫品虚增为六张；RKCB 后的签约不再误识别为 Stayman 或新花色。

## 加倍

- 区分直接技术性加倍、负加倍、对 Michaels／Unusual 2NT 的实力加倍、直接对 1NT 的惩罚性加倍和竞争后的惩罚性加倍。
- `1低花–(1♥)` 后五张黑桃自然叫 `1♠`；`1低花–(1♠)` 后四张红心负加倍，五张红心且 10+ HCP 自然叫 `2♥`，不再把自然五张套一律塞入负加倍。
- 竞争后的惩罚性加倍要求 4+ 张敌方将牌、至少两个将牌大牌、足够快速赢墩及保守的点力门槛；对手有局只降低一点 HCP 门槛。
- 新增 1,255 个加倍审计位置，其中 1,240 个用于确认缺少四张敌方将牌或不足最低点力时绝不作惩罚性加倍。

## 完整随机牌局

- 10,000 副固定种子的四机器人完整拍卖全部结束，共逐步检查 89,764 次叫牌决策；包含 4,249 副双方竞争、1,117 副重度竞争、1,387 副长拍卖、461 个进局逼叫节点、417 个半逼叫开叫人再叫节点和 74 次惩罚性加倍，硬规则违规为 0。
- 另跑 10,000 副固定种子的无干扰完整拍卖，用于审查自然序列与公开点力下限。随机拍卖承担异常发现和状态覆盖；规范性结论仍由有独立预期的逐步矩阵判定。
- 再用一批全新种子运行 50,000 副完整拍卖，共逐步审计 420,156 次决策；包含 16,446 副双方竞争、4,121 副重度竞争和 6,054 副至少 12 次叫牌动作的长序列。逐步检查合法性、逼叫、点力和套长承诺、无将范围、已知配合以及上下文叫牌说明，违规为 0；每副完整轨迹均以压缩 JSONL 保存。
