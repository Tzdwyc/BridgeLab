# v3.2.2 手机牌桌界面范围

本次仅调整呈现。单机与联机共用 TrickScoreMeter，在原有手牌下方的计分位置显示定约（含加倍、再加倍）、实际庄家方位、南北与东西已得墩数、原有双柱与目标线、简短成约状态。手机横屏与竖屏使用同一区域。电脑宽屏继续使用原有定约位置与双柱布局。

手机隐藏四个座位可见的余牌张数及计分区以外重复出现的定约。保留方位、明手身份、当前行动、已有 HCP、单行自家手牌、明手四列、完整叫牌记录，以及“叫牌记录”“上一墩”两个按钮。南北与东西计数始终对应真实方位，不随联机玩家视角旋转。

页头与四项底部导航保持固定；短屏由中间 main 区滚动。手机原生覆盖样式的唯一配套调整为允许 tableMain 纵向滚动。浏览器测试直接读取 ../v3.2.2-mobile/mobile-overrides/mobile.css，与候选 APK 使用同一份覆盖样式。

手机主状态使用“还差 2 墩”“已够墩”“至少宕 1 墩”；结算后显示“成约”“超 1 墩”“宕 1 墩”。仅据公开已得墩、目标与最终结算生成。电脑端继续显示原有长文案，trickScoreState 的计数和判定未改。
