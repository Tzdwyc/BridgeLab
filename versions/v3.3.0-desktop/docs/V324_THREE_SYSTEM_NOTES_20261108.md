本轮修正三处说明问题：

1. 弱跳争叫后，旁门特征回答如果恰好叫回敌人的开叫花色，原提示会误写成“最低限或无可显示的旁门A/K”。现在按已分类的旁门特征回答显示相应花色A或K。该错误由既有6888前缀下合法3♥按钮提示复现，不宣称3♥出现在本批912次实际返回叫品中。
2. 精确制1♣遭1NT干扰后的等待不叫，补上“同伴须再自然描述”；1♣遭3NT等高位干扰时不添加此义务。
3. 精确短方块4405回答只显示一次完整牌型，保留方块缺门和逼叫一轮，不重复列四门套长。

单机、联机的人工按钮与落桌记录，以及分析室逐叫记录，共用悬停、长按提示组件。解释仍根据当时前缀和所用体系生成；旧存档仍遵守约定版本保护。短点原有叫牌、发送和复盘动作均保留，长按只查看注释。提示不再因无关重渲染关闭；真正换牌局或叫牌上下文时关闭。

验证包括51项说明测试、完整构建、正式构建页面三体系按钮和已落桌记录6项核对，以及实际UI组件独立测试页19项交互核对。独立组件页不代表真实LAN网络验收。所有选叫、core、controller和public资产的原有文件逐字节一致，只有presentation文件及注释UI文件在本轮变更范围内。Android安装包另行核对版本、签名和嵌入资源；本轮未安装到实体手机或模拟器。
