## 修复方式与保护边界

一致性层取消“现有规则给Pass就保留原错误叫品”的特殊阻挡。替代Pass仍必须通过原assessCandidates检查；未完成问答、F1、独立GF及公开成局条件仍会拒绝不合格Pass，没有把过手新套强行改成逼叫。

仅cue-response复用公开语义层现有pendingResponseViolation成员判断。自然真实回答可通过，原认可人工例外仍须满足自己的资源条件；其他人工问答的明确叫品集合、角色、套长及点力限制不变。没有把例外角色名单泛化为所有人工叫均允许。
