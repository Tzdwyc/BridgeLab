# v3.2.8 验收说明

本版修复叫牌提示及已有问答约定的执行，并恢复STOP。继续默认旧seed 101第8轮，保留原SL回退；前瞻关闭，未追加训练，未增加叫牌资源门槛，打牌引擎和原存档键不变。v3.2.7原源码及发布包保留。

## 修复内容

- 候选、实叫记录及复盘使用相同的公开含义；按原牌局记录的体系和协议版本解释，原始存档不被重写。真正缺失的旧约定资料保留边界说明。
- 不再盲目继承前轮点力与配合；区分人工问叫、自然长套、关键张、控制、邀请、不逼叫和成局止叫。精确制强1♣后的1NT正应不会再被描述成弱长低花。
- 原1NT遇对手插叫、同伴弱长低花逃叫后，自然3NT保留原点窗；修复倒置的20～17点提示。
- 既有公开问答义务不再被默认模型的合法但违约Pass绕过，包括敌方随后自然叫方块的扣叫回答，以及低花接力。只使用现有规则给出的合格替代，不新排答案；没有合格替代的诊断反例继续保留。
- 自然争叫、应叫及人工问叫遵守已有资源资格，提示不会根据私有手牌被改成迁就错误叫品的含义。
- 单机和联机的候选及已叫记录恢复红色STOP；普通不跳叫和最低被迫回答不误标。只显示静态标记，不弹通知。
