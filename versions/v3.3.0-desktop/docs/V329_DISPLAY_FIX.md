# v3.2.9 当前实叫提示修复

v3.2.8将当前实叫记录接入了要求约定版本完全匹配的历史解释入口。旧存档缺失或带旧版本号时，体系已经明确，整条实叫含义仍被统一屏蔽为“原约定含义未记录”。这是显示判断错误，与牌或叫牌规则无关，上一轮验收结论不应外推到该恢复路径。

本版当前牌桌直接使用与候选相同的公开解释入口，按实际gameSystem与已发生叫牌前序生成提示，不再以存档版本号是否相同为显示前提。STOP不变，叫牌选择、模型、规则和打牌引擎不动，原存档不删除、不改写为新版本。

验证严格沿用原第540副同一个1♥动作，只切换保存元信息：当前版本、缺版本、旧版本、缺逐局字段、再缺顶层体系字段。冻结机器人，不新开牌、不加Pass、不追加动作、不增加母牌，也不重新验收历史牌例。

现有提示入口测试46项通过。最终生产页面恢复结果、文件校验与发布包签名见[本次证据](../artifacts/v329-history-display-20261108/)；最终收据FINAL_ACCEPTANCE.json在发布包生成后留在包外，避免自引用。实体手机安装和真实多设备网络不属于本次核验。
