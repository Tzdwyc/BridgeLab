# BridgeLab v3.3.0 Android

Android 安装包：[BridgeLab-v3.3.0-mobile-android.apk](https://github.com/Tzdwyc/BridgeLab/releases/download/v3.3.0/BridgeLab-v3.3.0-mobile-android.apk)。

Android版版本号为3.3.0+70，与桌面版使用相同网页资源，提供叫牌、打牌、牌例编辑和逐墩分析。

可选标准（SAYC）、自然（Natural）与精确（Precise）。标准采用SAYC的二盖一逼叫一轮、非逼叫1NT及Blackwood／Gerber；自然沿用v3.2.9默认混合二盖一与1430，并新增单路反式Drury；精确保持原有约定。详细范围见应用内体系卡与[版本说明](../v3.3.0-desktop/docs/V330_CHANGES.md)。

打牌使用固定的实战配置，恢复旧存档时同样生效，无需用户设定。叫牌提供默认引擎与备用引擎。v3.2.9原目录与存档保留。

构建与升级签名验证结果见docs目录的发布记录。尚未进行实体手机安装、升级和离线使用验证。
