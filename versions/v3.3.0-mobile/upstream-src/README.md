# BridgeLab v3.3.0

BridgeLab 提供叫牌、打牌、牌例编辑和逐墩分析。你坐南家，与北家搭档；可保存牌局、悔牌、重打，并查看叫品说明。

本版提供三套叫牌体系：

- 标准（SAYC）：五张高花，二盖一逼叫一轮；高花开叫后的1NT为6–10点、不逼叫。低花开叫后的直接2NT为13–15点、逼叫进局，3NT为16–18点。满贯问叫采用Blackwood与Gerber。
- 自然（Natural）：沿用v3.2.9默认体系的混合二盖一与1430关键张问叫，仅新增单路反式Drury。已Pass的应叫人面对同伴第三、第四家一阶高花开叫，在应叫前无敌方干扰时，可用人工2♣表示10–12支持点、三张以上支持；开叫人最低回原高花表示无进局兴趣、止叫，2♦为人工建设性回答并继续一轮。
- 精确（Precise）：保留原有精确体系。

四位牌手使用同一套约定，具体范围以应用内体系卡为准。切换体系从下一副、新牌局或重打时生效。

打牌使用固定的实战配置，无需手动选择。恢复旧存档也使用同一配置。叫牌提供默认引擎与备用引擎。

桌面版启动入口为本目录下的“启动BridgeLab-v3.3.0.cmd”。Android版为3.3.0+70，两端使用相同网页资源。v3.2.9原目录与存档保留。
