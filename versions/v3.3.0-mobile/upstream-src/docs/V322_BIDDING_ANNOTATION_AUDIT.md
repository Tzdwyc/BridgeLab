# v3.2.2 叫牌注释核查

本次只修改叫品说明的呈现。叫牌决策、规则、结构化约定、模型、训练和打牌算法保持原样。全部说明仅使用所选叫品之前的公开叫牌，不读取任何一家的暗牌，也不使用后续叫品倒推当时含义。

## 统一入口

单机按钮与叫牌表、LAN 叫牌表、比赛记录继续通过 `describeCall` 取得说明。该入口改为调用 `bidding-presentation.ts`：先辨认当前公开角色，再分别显示点力、套长、支持点和逼叫状态。旧引擎文字仍保留为内部历史材料，没有拿它替代新显示的验收。

分析室与比赛历史使用 `historical-bidding-presentation.ts`。只有原存档所记体系及约定版本与当前配置完全相符时，才重新呈现当前简短解释；版本未知或不同则保留并标记原存档说明，或说明无法确定。原始存档、冻结说明和机器人调整原因不被改写。分析室不再展示当前引擎参考解释等开发用前缀。

旧版简化自然制单独处理，不自动套用高花转移、二盖一逼局、Michaels 或关键张约定。只对旧引擎明确具有的 1NT／2NT／3NT 开叫给点力和均型说明；直接 4NT 及以上不虚构 23 点均型含义。

## 核查范围与结果

- 已冻结的 108 副 v3.3.1 牌局：只重放既有公开叫牌前缀，共 1,034 个叫品、33 类公开角色；没有生成新牌，没有重跑叫牌策略或打牌模拟。
- 这 1,034 条说明平均由 40.26 字缩至 28.59 字，最长由 223 字缩至 92 字。14 条当前结构化约定本就未定义，明确显示未约定，不借用另一序列的自然叫或人工叫含义。全部前后文字和前缀保存在 `artifacts/v322-bidding-frozen108-before-after.json`。
- 从原有两个逐例审读表提取 138 条公开前缀，并补入 36 条四体系对照，形成 174 行前后解释记录，保存在 `artifacts/v322-bidding-existing-fixtures-before-after.json`。另有旧表中的内联个案，由表格维护核查单独覆盖。
- 新增 25 项针对性测试，加上三个既有悬浮说明测试文件的 28 项，共 53 项通过。新增测试中的批量核查遍历四种体系、六个公开前缀的所有合法叫品，验证公开结构化含义在显示前后完全一致。
- 首轮五个旧说明测试文件在基线为 201／203 通过，已有两项失败；新显示的首次运行连同 17 项新测试为 100／220 通过。初始失败记录保留，没有通过跳过测试或改回旧显示来隐藏变化。旧的冗长字符串断言须按同一公开事实改写；最终全套测试与整包验收以发布总报告为准。后续全套测试又定位 29 项旧文字片段断言：三个文件只更新同一公开事实的中文写法，保留全部叫牌、手牌、决策和结构化断言；这些文件连同新增显示测试共 156 项通过，见 `artifacts/v322-bidding-29-prose-regressions.json`。
- 独立校验本次负责范围内的 46 个 AI、规则、控制器、比赛和模型文件，前后哈希相同。`bidding.ts` 中说明入口之前的决策代码逐字一致；内部保留的原说明函数正文逐字一致。证据见 `artifacts/v322-bidding-source-invariance.json`。整包更广范围的源文件保护由发布验收另行核对。

## 重点纠错与保留的事实

| 公开情境 | 新显示的核心事实 |
|---|---|
| 开叫前不叫 | 表示本轮不参与，不据此断言牌力不足 |
| 精确 2♣—2♦ 后 2♥／2NT／3♣ | 只解释所选回答，不并列其他回答的点档 |
| 精确 2♦—2NT 后 3♣ | 明确本次为 4=4=1=4 人工牌型回答，并须自然签约 |
| 1NT 后 2♦，与受花色干扰后的自然二阶应叫 | 分清转移目标套和自然叫出的套 |
| 转移未答，与已经完成的自然高花接受 | 分清尚须回答和允许停叫；连续不叫不把未答人工转移变成可签约定约 |
| 真实 1NT 完成 Stayman 的 2♦ 回答 | 本轮询问已经完成，允许按真实方块接受部分定约；不沿用旧测试中禁止不叫的过时要求 |
| 未不叫过的二盖一，以及已经不叫过的手牌 | 保留进局逼叫与非逼叫的差别；已有逼局不会因普通自然续叫丢失 |
| 1♣—1♦—1♥—1♠ | 本卡的一阶第四花色为自然黑桃；未过手逼叫一轮，过手不逼叫 |
| 技术、平衡位、再开叫和响应性加倍 | 使用实际公开分类，不能统称惩罚；无已知分类时不虚构惩罚含义 |
| 负加倍、人工花色上的首攻指示加倍 | 显示具体未叫花色；人工无将问叫上的加倍不编造具体首攻方向 |
| 精确强 1♣ 受加倍后的再加倍 | 8 点以上人工正应、逼局，区别于普通实力再加倍 |
| 支持性扣叫后的自然支持 | 保留此前 10 点以上支持点与三张支持，不降为两张偏好 |
| 两张偏好、竞争性支持、转移后的支持 | 显示同伴当时已公开的长度；未确认八张配合时不虚加短门点 |
| 自然重复套、接受邀请、最低被迫回答 | 保留此前点力与长度、邀请来源和本轮回答义务，不因重复叫牌凭空增加六张或 17／18 点门槛 |
| 自然 4NT／5NT，与有将牌约定的 4NT／5NT | 分清定量邀请和关键张／旁门 K 询问；保留可否不叫和至少到六阶的义务 |
| 关键张回答、将牌 Q 回答与旁门 K 回答 | 明确将牌 Q 的否认、有 Q 及旁门 K 回答；六阶将牌回叫只否认其下可显示的旁门 K，不否认更高花色 K；一张旁门 K 不等于保证十三墩或接受大满贯 |

## 保留的结构化冲突

按本次确认的既有约定，SAYC 与独立二盖一体系在强 2♣—2♦ 等待—3♦ 后，3♥ 是 0–3 点人工二次负应，3NT 是 4 点以上自然正应；最低原套回答后可止叫，自然 3NT 可签约。

旧结构化函数 `strongSecondNegativeAt` 仍把此处 3NT 分类为二次负应，而同一文件的移位 4♥ 正应说明又明确保留 3♥ 给负应。由于本次不改叫牌决策或结构化字段，显示层按已经确认的约定使用专门模板，测试同时检查两个体系的 3♥、3NT、4♥、负应后的 4♦ 和自然 3NT 后的不叫。此处不能据显示修正宣称底层叫牌协议或模型也已经修复。

同样，旧长段落中关于普通自然争叫可凭优质六张长套降低点力的泛化表述，若当前结构化约定没有对应分支，本次不凭空给出新的点力范围。显示保留有明确结构化补偿条件的长套例外；其他范围边界留在证据中，不作为新增叫牌规则。

上述数量说明的是有限公开前缀的注释核查，不是所有桥牌约定的穷举正确性证明。Android、浏览器交互及整包测试由发布验收另行记录。
