## 实现

SAYC和二盖一采用3♥为0–3点人工二负、3NT为4点以上自然正应可止叫、五张红心正应移4♥；人工负应不许推断红心长度。3♥后开叫人回答最低4♦，随后可停。说明、结构化点力套长、逼叫状态、规则选叫和单机入口一致。

6888保留现有25点高花门槛，仅纠正询问阶段：首次2NT询问仍须回答，旁门特征回答完后允许自然签约4♠，不再把询问人的签约误当作尚待完成的三阶回答。

支持扣叫后只放行既有公开将牌可独立识别的RKCB4NT，其他不合协议的人工回答仍拒绝。竞争问叫之后的实际机器人按现有1430回答。

单机原网络仅过滤法律合法性，无法保证上述协议回答。新增入口适配严格限定为上述强2♣阶段、SAYC弱跳争叫特征问答和已识别的竞争RKCB回答，复用现有规则决定；其他位置继续使用原网络及既有补丁。原SL和第8轮权重均未修改。

自然体系约定标识升为v2.2，房主与客人双向拒绝旧或缺失标识，避免混用3♥/3NT含义。历史v2.1存档保留原说明。
