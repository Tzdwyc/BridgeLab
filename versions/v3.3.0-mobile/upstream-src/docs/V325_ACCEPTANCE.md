## 4NT首叫与说明层

此前程序没有首叫4NT双低套合同，落入普通自然无将说明。本轮按用户明确要求，给SAYC/2/1混合卡明示人工C5+D5、无新增HCP窗口、逼同伴选择最低5♣或5♦。同伴被迫低花选择不要求三张支持或独立成局实力，回答后可停；后续定量4NT、RKCB及精确制由首叫守卫隔离。没有添加新的机器人4NT开叫生成或概率规则。

新增协议正反测试与8次实际机器人低花应答均通过，包括被加倍后继续选择。真实落桌曾暴露“泛用自主高阶选叫过滤器拦住四张方块选择，反而退到单张梅花”的问题；已使明确被迫选择按同一公开协议校验，四张对单张正常选较长低花。相关首失败记录与修复前探针保留。另一次协议测试最初用了错误花色顺序，已标记测试夹具问题并改用原固定手牌，不把失败数据当正式牌力证据。

说明使用现有角色、前缀和逼叫字段区分：普通NF允许继续；邀请低限可停；明确选定自然成局写成局止叫；转移后的3NT保留同伴改选高花权利；首叫人工4NT要求回答，最低低花回答才可停。自然弱二、三阶及四阶阻击明确标出性质，不因改词改变点窗或牌型。正式页面两体系10项手机视口悬停检查通过，实际加载第8轮权重哈希已核。
