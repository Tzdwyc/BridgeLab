# BridgeLab v3.3.0 版本说明

桌面版与Android版同步调整叫牌体系选择和说明，Android版本为3.3.0+70。

## 三套叫牌体系

| 体系 | 主要约定 |
| --- | --- |
| 标准（SAYC） | 五张高花；二盖一逼叫一轮；高花开叫后的1NT为6–10点、不逼叫；低花开叫后的直接2NT为13–15点、逼叫进局，3NT为16–18点；Blackwood与Gerber问A。 |
| 自然（Natural） | 沿用v3.2.9默认混合二盖一与1430关键张问叫，仅新增单路反式Drury。 |
| 精确（Precise） | 保留既有精确体系。 |

自然体系的单路反式Drury适用于已Pass的应叫人，面对同伴第三、第四家的一阶高花开叫，在应叫前无敌方干扰时，以人工2♣表示10–12支持点、三张以上支持。开叫人最低回原高花表示无进局兴趣、止叫，2♦为人工建设性回答并继续一轮。具体适用条件与后续叫品见应用内体系卡。

## 使用方式

四位牌手使用同一套约定，切换体系从下一副、新牌局或重打时生效。叫牌引擎以“默认引擎”和“备用引擎”显示。

打牌采用固定的实战配置，用户无需设定；旧存档恢复后也使用该配置。原有保存、牌例编辑、悔牌、重打与分析入口继续使用。

桌面版启动“启动BridgeLab-v3.3.0.cmd”；Android版使用同一份网页资源。v3.2.9原目录保留，原存档不删除。

196项相关回归通过，既有33个位置在两档真实模型下共66组选叫与原默认档一致；桌面及手机布局的Drury实际落桌和提示检查通过。构建、安装包和升级签名结果见发布记录；尚未进行实体手机安装、升级及离线使用验证。
